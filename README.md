# ⏰ Timer OBS - ตัวแสดงเวลาปัจจุบัน & อ่านเวลาภาษาไทยฟรี (Free Thai TTS)

โปรแกรมแสดงเวลาปัจจุบัน (Real-time Clock Overlay) พร้อมระบบอ่านเวลาภาษาไทยฟรี, เสียงเอฟเฟกต์นาฬิกาปลุก, รองรับ Google Fonts ภาษาไทย และปรับแต่งสี/พื้นหลังได้อย่างอิสระ ออกแบบมาสำหรับ **OBS Studio**, ไลฟ์สตรีม และใช้งานทั่วไปบนเว็บเบราว์เซอร์

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **แสดงตัวอย่างแบบสดชัดเจน (Dual Live Preview)**:
   - **พรีวิวในแผงตั้งค่า**: มีกรอบ Live Preview พินอยู่ด้านบนของแถบตั้งค่า อัปเดตตามการปรับค่าทันที พร้อมปุ่มสลับพื้นหลังจำลอง (🏁 โปร่งใส, ⬛ มืด, ⬜ สว่าง, 🎮 ฉากเกม) เพื่อเช็คความคมชัด
   - **นาฬิกาหลักบนหน้าจอไม่โดนบัง**: เมื่อกดเปิดแผงตั้งค่า นาฬิกาหลักบนหน้าจอจะขยับหลบไปทางซ้ายโดยไม่มีฉากหลังมืดหรือเบลอมาบดบัง ทำให้เห็นผลลัพธ์ขนาดจริงได้ 100%
2. **แสดงเวลาและวันที่แบบ Real-time**:
   - ความแม่นยำสูงระดับมิลลิวินาที
   - ปรับเป็นแบบ 12 ชม. (AM/PM) หรือ 24 ชม. ได้
   - เปิด/ปิดการแสดงวินาที และเลือกรูปแบบวันที่ (ไทยเต็ม / ไทยย่อ / อังกฤษ)
3. **ระบบอ่านเวลา Google TTS ภาษาไทยฟรี (เสียงธรรมชาติที่สุด)**:
   - ใช้ **Google Translate Thai Voice** เสียงพูดกูเกิลแปลภาษาแท้ คมชัด สำเนียงธรรมชาติ ไพเราะ และฟรี 100% ไม่ต้องใช้ API Key
   - มีระบบวรรคตอนภาษาไทยอย่างถูกต้อง เช่น `14:05` ➔ *"สิบสี่นาฬิกา ห้านาที ค่ะ"*
   - ปรับความเร็ว (Speed Rate) และระดับเสียง (Volume) ได้อย่างอิสระ
   - มีระบบสำรอง (Fallback) สลับไปยัง Web Speech API อัตโนมัติกรณีออฟไลน์
4. **ระบบเสียงเอฟเฟกต์นาฬิกาปลุก (Alarm Sound FX)**:
   - สร้างเสียงเตือนด้วย **Web Audio API** คมชัด โหลดไว 100% ไม่มีปัญหาเน็ตหลุด
   - มี 5 เสียงสำเร็จรูป:
     - 🔔 **Chime**: กระดิ่งกังวาน นุ่มนวล
     - ⏰ **Digital Alarm**: บี๊บ ๆ นาฬิกาดิจิทัล
     - 🎵 **Ding-Dong**: ติ๊งต่องสองโทน
     - 🎶 **Marimba**: มาริมบาสไตล์โมเดิร์น
     - 🕰️ **Clock Bell**: ระฆังนาฬิกาโบราณ
   - รองรับการใส่ URL ไฟล์เสียงของตัวเองได้ (Custom Audio)
5. **🔇 ระบบปิดเสียงทั้งหมด (Master Mute All)**:
   - กดปุ่ม **`M`** บนคีย์บอร์ด หรือคลิกปุ่มลำโพง เพื่อปิด/เปิดเสียงทั้งหมดได้ทันที
   - ระงับทั้งเสียงปลุกและเสียงอ่านเวลาพร้อมกัน
6. **เพิ่มกฎการเตือนเวลาได้อิสระ (Custom Schedules)**:
   - แบบช่วงเวลาสม่ำเสมอ: ทุก 15, 30, 60 นาที หรือกำหนดเอง
   - แบบระบุเวลาเจาะจง: เช่น `12:00`, `18:00`
   - เลือกโหมดได้: *เสียงปลุกอย่างเดียว*, *อ่านเวลาอย่างเดียว*, หรือ *เสียงปลุกนำก่อนแล้วอ่านเวลา*
   - ปรับแต่งข้อความคำพูดด้วยตัวแปร `{time}`, `{date}`, `{hour}`, `{minute}`
7. **ปรับแต่ง Google Fonts & สไตล์ภาพ**:
   - คัดสรรฟอนต์ไทยยอดนิยมจาก Google Fonts พร้อมตัวเลือกพิมพ์ชื่อฟอนต์จาก Google Fonts ได้อิสระ
   - ปรับขนาด, น้ำหนัก, สีตัวอักษร, ขอบตัวหนังสือ (Stroke), และเงา (Shadow)
   - ปรับพื้นหลัง: ทั้งแบบโปร่งใส 100% (Transparent) สำหรับ OBS หรือแบบกล่องมน ปรับความทึบแสง (Opacity) ได้ตามใจชอบ
8. **บันทึกการตั้งค่าอัตโนมัติ**:
   - บันทึกลง `localStorage` และมีปุ่ม Export/Import ไฟล์ `.json`

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดใช้งานทั่วไป (บนเบราว์เซอร์)
- ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge หรือ Brave) ได้ทันที
- คลิกปุ่ม **"⚙️ ตั้งค่า"** ด้านล่างเพื่อปรับแต่งสไตล์และเพิ่มกฎการเตือนเวลา

### 2. วิธีนำไปใส่ใน OBS Studio (Browser Source)

1. เปิดหน้าจอปกติ แล้วคลิกปุ่ม **"📋 ก๊อปปี้ลิงก์ OBS"** (จะได้ URL ที่ลงท้ายด้วย `?mode=overlay` เช่น `file:///.../index.html?mode=overlay`)
2. ในโปรแกรม **OBS Studio**:
   - ในช่อง **Sources** กดปุ่ม `+` แล้วเลือก **Browser**
   - ตั้งชื่อ Source เช่น `Clock-Overlay`
   - ในช่อง **URL**: วางลิงก์ที่คัดลอกมา (หรือติ๊กเลือก *Local file* แล้วเลือกไฟล์ `index.html`)
   - กำหนด **Width**: `800`, **Height**: `250` (หรือปรับขนาดตามต้องการ)
   - ⚠️ **สำคัญมาก:** ติ๊กถูกที่ช่อง **"Control audio via OBS"** เพื่อให้เสียงเตือนและเสียงพูดถูกส่งเข้าไปยัง OBS Audio Mixer
3. กด **OK** ➔ นาฬิกาจะแสดงบนหน้าจอ OBS อย่างสวยงามโดยไม่มีแถบปุ่มใด ๆ รบกวน
